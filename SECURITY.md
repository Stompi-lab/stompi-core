# Security / Sicherheit

Report Stompi vulnerabilities privately to **thomas@stompi.de**. Please include the version, affected component and reproduction steps. Do not post private keys or recovery words.

Stompi-Sicherheitsprobleme bitte vertraulich an **thomas@stompi.de** melden. Keine privaten Schlüssel oder Wiederherstellungswörter veröffentlichen.

There is no independent security audit claimed for this source snapshot.
